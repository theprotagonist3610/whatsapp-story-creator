# Icônes PWA

Remplacer ces fichiers par les vraies icônes PNG de la marque :

- `icon-192x192.png` — icône Android / PWA (192×192 px)
- `icon-512x512.png` — icône PWA haute résolution (512×512 px)
- `apple-touch-icon.png` — icône iOS (180×180 px)

Le fichier SVG est un placeholder temporaire.

Pour générer les PNG depuis un SVG : `npx @vite-pwa/assets-generator`
